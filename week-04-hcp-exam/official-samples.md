# Official sample questions (do this before mocks)

Format drill. HashiCorp’s wording, not this repo’s.

Open: [Sample Questions — Terraform Associate 004](https://developer.hashicorp.com/terraform/tutorials/certification-004/associate-questions-004)

Three item types on 004:

1. **True / false** — one statement. Watch absolute words (always, never, only).
2. **Multiple choice** — one correct option.
3. **Multiple answer** — the stem says how many. All required options must be selected.

Work every official item. Write the objective id (1a–8d) next to each miss. Restudy that row on the [content list](https://developer.hashicorp.com/terraform/tutorials/certification-004/associate-review-004).

Then [mock-01.md](mock-01.md), [mock-02.md](mock-02.md), [mock-03.md](mock-03.md). Sixty minutes each. Score by objective, not a made-up pass %.
